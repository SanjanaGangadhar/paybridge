# PayBridge Blockchain Layer

The blockchain layer is designed to provide a tamper-evident verification mechanism for financial credentials and consent events.

## Planned Responsibilities

- Credential proof anchoring
- Hash verification
- Consent-event recording
- Credential issuer verification
- Audit references

## Design Principle

Sensitive financial and personally identifiable information should remain off-chain.

The blockchain layer is intended for proofs, verification references, and selected audit events.

## Planned Technology

- Drunix-supported blockchain infrastructure
- Smart contracts
- Web3
- Cryptographic hashing
- Verifiable credentials

## Current Status

Proposed architecture / prototype-development stage.
